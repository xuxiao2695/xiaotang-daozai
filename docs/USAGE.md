# 使用指南

## 第一次打开

鼠标靠近屏幕顶部的小岛会展开功能面板。左右箭头和底部圆点切换页面；在列表内部滚轮查看更多内容。托盘菜单可打开设置、控制开机启动或退出程序。

设置里的功能显示开关可以隐藏不常用的页面；隐藏页面不等于删除它的数据。

## 邮箱

在「设置 → 邮件」添加完整邮箱地址，选择服务商并填写授权码或 App 专用密码。不要把密码发送到聊天、Issue 或截图里。

| 邮箱 | 获取连接凭据 |
| --- | --- |
| QQ | QQ 邮箱网页版右上角「设置」→「账号与安全」→「安全设置」→「POP3/IMAP/SMTP/Exchange/CardDAV 服务」→开启服务并生成授权码 |
| 163／126 | 邮箱网页版「设置」→「POP3/SMTP/IMAP」→开启 IMAP，并按页面验证生成客户端授权密码 |
| 腾讯企业邮 | 网页版设置中的客户端收发设置；企业管理员可能限制 IMAP 或第三方客户端 |
| iCloud | Apple 账号开启双重认证后，在账号安全页面生成 App 专用密码 |
| Gmail | Google 账号开启两步验证后生成应用专用密码；单位账号可能由管理员禁用此入口 |

以服务商当前页面为准，岛仔设置页也提供对应说明和网页入口。Gmail 在部分网络环境下需要能够访问 Google；岛仔不会替你改变系统网络设置。

连接后读取最近 20 封邮件；运行期间列表最多保留 60 封。新邮件优先通过 IMAP IDLE 接收，并有定期防漏检查；服务器、网络及服务商投递耗时仍会影响实际到达时间。

验证码卡片显示来源与主题，点击即可复制。点邮件列表进入详情，滚轮查看正文；「阅读全文」打开独立阅读窗口。正文内的网页链接交给默认浏览器打开。

邮件列表可切换「全部／未读」。打开邮件后会标为已读，也可在邮件行、详情或全文窗口手动切换已读状态。删除会移到当前模式的回收站；点击列表右下角的垃圾桶图标进入回收站，可将邮件恢复到收件箱。「设置 → 邮件 → 同步邮件操作到邮箱」默认关闭，仅在本机保存整理状态，不改动真实邮箱；开启后已读、删除和恢复同步服务器，失败时保留列表记录并提示。远程删除和恢复要求邮箱支持 IMAP MOVE。仅提供 UIDPLUS 的邮箱可使用本机回收站。切换开关不会补交之前的本机操作。

列表和筛选数量对应当前加载的最近邮件；仅本机模式下「全部已读」只处理当前加载的记录；开启同步后会处理已连接邮箱的全部未读邮件，不限于列表记录。常规状态刷新只读取最近邮件标记，正文优先复用内存缓存。

## 日程

在「设置 → 日程」选择平台，填写平台提供的 CalDAV 连接信息。只登录或安装飞书、钉钉、企业微信桌面客户端，不会自动授予岛仔日历读取权限。

- 左侧月历选择日期；右侧按时间显示日程，全天安排在前。
- 大卡片显示选中的日程；滚轮只滚动下方列表，点击其他条目切换大卡片。
- 跨天日程会出现在覆盖的日期中。结束时刻按日历提供的数据展示。
- 自动同步默认每 5 分钟进行；点击右上角更新时间可手动刷新月份。
- 提前提醒时间可在设置中选择 5／15／30 分钟；全天安排展示在日历中，不在午夜弹出会议提醒。
- 普通邮件正文中的日期不会加入日程；带日历附件的正式邀请会自动显示。
- 邮件日程右侧的 × 可忽略该日程，停止显示与提醒；在邮件详情或全文窗口选择「恢复日程」可恢复。忽略邮件来源不会删除工作日历中的对应安排。

**当前边界：** 邮件日程依赖当前加载的邮件记录，不是完整邮箱归档；复杂的批量重复规则修改可能提示不支持。日历同步失败会显示错误，不能把“已连接”当成所有日程都已成功同步。程序退出、电脑关机或睡眠期间无法持续接收提醒。

## 音乐、专注、饮水与待办

音乐来自 Windows 媒体会话，播放器需要提供系统媒体信息。歌词匹配依赖歌曲元数据和外部服务，个别版本、纯音乐或未找到歌词的歌曲可能无法显示同步歌词。

专注与休息需点击开始，结束后可进入下一阶段。饮水可设置目标、单次量、提醒间隔和时段；记录错误可以撤销。待办提醒是可选项，填写任务后通过日期／时间选择器设置，不需要手写时间格式。

## 界面大小

觉得岛上的字太小时，在 设置 → 常规 → 界面大小 选 125%–200%。岛和设置窗口会一起放大；如果放大后整块画布超过屏幕宽度，会自动限制在能完整显示的最大倍数。

## 小工具

岛仔可以和本机的四个小工具联动：自动亮度（AutoBrightness）、语音输入（VoiceInput）、DeskHub（Claude 提醒、会议与专注）、自动睿频（AutoBoost）。岛仔没开时，各工具照常用自己原来的提示方式，互不影响。

### 岛上的实时提示

各工具把状态推给岛仔本机端口 `127.0.0.1:47820`（只接受本机连接；端口被占用时岛仔照常运行，只是没有联动，原因写在 `%APPDATA%\Daozai\diagnostics\integrations.log`）：

- 语音输入：按住听写键时，收起的岛变成红色麦克风和跳动的音量条，显示麦克风名称（F14 指令模式带「命令」标记）；松手后显示「识别中…」，完成后显示 ✓ 和识别结果约 2 秒，指令模式再显示 DeskHub 的回复约 3 秒。听写期间其它提醒排在后面，结束后继续显示。岛仔显示时，VoiceInput 不再弹出自己底部的浮窗。
- 自动亮度：调节亮度时显示约 2.5 秒的亮度条；久坐、坐姿、护眼提醒以卡片显示，点「知道了」关闭；离座黑屏前显示「N 秒后黑屏 · 动一下鼠标取消」倒计时。
- DeskHub：Claude 要你批准或在等你回复时显示琥珀色提醒，Claude 做完显示绿色提醒；专注结束时显示「专注结束 · 期间错过 N 条」。
- 自动睿频：开启睿频时显示「已开启睿频 · 原因」，回到省电时显示「已回到省电」。

### 常驻指示

收起的岛上最多常驻两个小图标，按优先级排列：Claude 在等你（琥珀色星芒，多个会话时带数字）> 会议中（红点）> DeskHub 专注中（紫色圆环，中间是剩余分钟）> 睿频中（橙色小闪电）。悬停可看说明，点一下打开「小工具」页。没有状态时不占位；空间不够时整组让位，不会把岛撑宽。可在 设置 → 页面管理 →「常驻排列」里拖动这组图标的位置。

### 「小工具」页

四张小卡片，每张显示运行状态（绿点运行中、灰点未运行、暗点未安装）、一行实时状态和一个按钮：

| 工具 | 实时状态 | 按钮 |
| --- | --- | --- |
| 自动亮度 | 当前亮度、下次测光或离座状态 | 打开 / 启动 |
| 语音输入 | 正在听的麦克风、识别中；空闲时显示听写键 | 打开 / 启动 |
| DeskHub | 等你批准的会话、专注剩余时间、会议中、播报开关 | 专注 25 分钟 / 清除提醒 / 结束专注；未运行时启动 |
| 自动睿频 | 睿频及原因、省电起始时间、暂停或强制睿频 | 睿频 1 小时 / 取消强制 / 恢复（右键暂停或恢复自动切换）；未运行时启动 |

- 运行判断：各自的单实例互斥体（AutoBoost 为 `Local\AutoBoost`），或最近收到它推来的状态。
- 没有实时数据时，读取 exe 同目录的 `config.json` 显示关键设置，只读不改；悬停卡片可看完整设置。
- DeskHub 的按钮通过它的本机控制口 `127.0.0.1:47800` 执行；AutoBoost 读写它文件夹里的 `state.json` / `control.json`（与它的托盘程序相同），未运行时用计划任务 `AutoBoost` 启动，不弹窗口。
- 没装时「获取」打开项目主页。

默认在 `%USERPROFILE%\AutoBrightness\AutoBrightness.exe`、`%USERPROFILE%\VoiceInput\VoiceInput.exe`、`%USERPROFILE%\DeskHub\DeskHub.exe` 和 `%USERPROFILE%\AutoBoost` 查找。装在别处时，在 `%APPDATA%\Daozai\tools.txt` 里逐行写（可以写 exe 路径，也可以写所在文件夹）：

```
autobrightness=D:\Apps\AutoBrightness\AutoBrightness.exe
voiceinput=D:\Apps\VoiceInput\VoiceInput.exe
deskhub=D:\Apps\DeskHub
autoboost=D:\Tools\AutoBoost\AutoBoost.ps1
```

### 设置

设置 → 页面管理 →「小工具联动」有四个开关，默认都开：在岛上显示语音输入、亮度提示、Claude 提醒（含会议与专注）、睿频提示。关掉某项后岛上不再显示，相应工具恢复自己的提示；关闭「岛仔提醒」时，除语音输入外的联动提示也一并不显示。下方显示联动端口的状态。

## AI 额度

先登录相应工具，再在岛仔 AI 额度设置中识别本机账号。多个账号可分别命名、选择配色并决定是否常驻。Codex、Claude、Kimi 的登录由各自客户端管理。Claude 桌面端只读本机历史和用量缓存，切换账号后需等待新记录。手动启用 Claude Code 本地采集时，岛仔会写入采集脚本并设置状态栏，已有其他状态栏命令时保留原配置。

Grok Bot、Gemini 提供各自的连接入口；会话过期时重新连接。额度接口、订阅类型和服务商策略可能变化，未识别或请求失败时应以对应服务的官方页面为准。

## 更新、卸载与数据目录

双击新版 `Daozai-Setup-v版本号-x64.exe`，可通过路径输入框或「浏览…」选择安装文件夹，勾选「创建桌面快捷方式」和「开机自启」，再点击「一键安装」。首次安装默认创建桌面快捷方式、不开机自启；升级默认保留现有选择。安装位置默认为 `%LOCALAPPDATA%\Programs\Daozai`，可改为其他有写入权限的文件夹，用户数据仍保存在 `%APPDATA%\Daozai`。

升级安装保留数据。若提示岛仔正在运行，先从托盘退出，再点击重试。

在 Windows 已安装应用中卸载会移除程序和快捷方式，但保留数据。若要清除账号，先在岛仔设置中移除对应连接，避免只删配置文件而留下系统凭据。

## 常见问题

**窗口没有出现：** 检查托盘是否已有实例、是否在全屏应用中、设置是否启用了全屏隐藏。

**邮箱登录失败：** 确认填的是授权码／App 专用密码、IMAP 已启用、账号没有被管理员限制。

**日程连接成功但没有安排：** 手动同步所选月份，确认平台授权的日历包含该日程；出现错误时保留错误文字即可，不要提供密码。

**验证码没有马上出现：** 确认邮件是否已到达收件箱，而非垃圾箱；检查岛仔是否运行、连接是否正常。

**图标或布局异常：** 反馈 Windows 版本、屏幕缩放比例、显示器数量和截图。截图先遮挡账号、验证码及私人日程。
